PROJECT DSA WORKFLOW

Data structures, put to work.

Explore the structures and algorithms used to organize and process XeroEasy print orders. Run each demonstration and inspect its output and complexity.

PHASE 01

Linear data structures

Store and update orders in a linked list, process work FIFO, manage actions LIFO, and evaluate a postfix expression with a stack.

Run a Phase 1 demo to see its output.
PHASE 02

Trees and graphs

Store structured data in a binary tree, organize orders in a binary search tree, and traverse campus services using BFS and DFS graph searches.

Run a Phase 2 demo to see its output.
PHASE 03

Searching and sorting

Find orders and compare insertion, merge, and quick sort; also order print jobs by copy count.

Run a Phase 3 demo to see its output.
PHASE 04

Algorithmic problem solving

Prioritize print orders greedily, optimize work with dynamic programming, and explore possible schedules through backtracking.

Run a Phase 4 demo to see its output.
